# competition — competitors and alternatives

Needed facts: product category, what the target uses today, claimed differentiation.
With `market` and a web search tool, find 3–5 competitors' prices and core features and cite URLs. Otherwise list names only and mark "assumption".

## Checks

1. Both direct competitors (same product) and indirect alternatives (spreadsheets, notes, marketplaces, doing nothing) are listed
2. The differentiation is one sentence from the user's point of view — ❌ feature list only
3. The differentiation is actually built in code — ✅ file:line / ⚠️ planned only
4. There's a reason competitors can't easily copy it (accumulated data, network, own products, distribution)
5. Switching cost from alternatives (data migration, signup friction) is considered
6. If we are pricier or equal, users can see why

## deep

- Table: `alternative | price | strength | weakness | conditions under which we win`.
- The most threatening alternative and a one-line response.
