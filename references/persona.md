# persona — user personas

Needed facts: target definition, segments, acquisition channels, feature list.

## Checks

1. The core target is defined by behavior ("people who do X"), not just demographics — ⚠️ demographics only
2. The target definition is marked as data or assumption — if assumption, is there a validation plan?
3. Each segment has its current problem and current alternative written down
4. Every core feature maps to at least one primary segment — ⚠️ list of features with no owner
5. If the payer and the user differ, both are defined
6. An anti-persona (who we are not targeting) exists
7. If acquisition channels differ by segment, onboarding handles them differently

## deep

- 2–3 personas, 5 lines each: `who / job to be done / where they get stuck / our feature / why it makes money`. Unsupported traits are "assumption".
- Persona × feature matrix (● primary, ○ occasional).
